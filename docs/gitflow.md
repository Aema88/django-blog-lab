# Git-flow workflow

У цьому проєкті використовується стратегія гілкування Git-flow.

## Основні гілки

- main — стабільна версія проєкту.
- develop — основна гілка для розробки.

## Додаткові гілки

- feature/* — гілки для розробки нового функціоналу.
- release/* — гілки для підготовки релізу.
- hotfix/* — гілки для термінових виправлень у стабільній версії.

## Приклад

Новий функціонал створюється у feature-гілці, після завершення об'єднується з develop.  
Коли версія готова до релізу, створюється release-гілка.  
Після перевірки release об'єднується в main і develop.
